# Scorio — Ranking Reasoning LLMs under Test-Time Scaling

From-scratch implementation of the ranking methodology from:

> Hariri, Hinczewski, Ma, Chaudhary,
> "Ranking Reasoning LLMs under Test-Time Scaling"
> arXiv:2603.10960 (2026). Code: https://github.com/mohsenhariri/scorio

The paper studies how the *choice of ranking rule* affects LLM leaderboards
when each model is evaluated by sampling N independent responses per question
(test-time scaling). Its central message: at large N the choice is cosmetic,
but at N=1 (single trial — the common case) it matters a lot, and there is a
proven minimal case where Bradley-Terry and average-accuracy disagree.

## Quick start

```bash
pip install numpy
python3 run.py
```

Output: four reproduced findings (high-budget agreement, low-budget best
methods, greedy-prior bias-variance, M_min=8 BT-vs-average counterexample)
plus an ASCII summary.

## What is implemented

| File | Purpose |
|------|---------|
| `rankings.py` | 8 representative ranking methods (pointwise / pairwise / Bayesian) + Kendall τ_b. Mirrors a subset of Scorio's 72-method API. |
| `data.py` | Synthetic response-tensor generator: L models × M questions × N trials with latent skill/difficulty, plus a greedy-decode prior R0. |
| `bt_vs_avg.py` | The Appendix-C theoretical result: constructs the exact M_min=8 counterexample + exhaustive no-disagreement search for M ≤ 7. |
| `run.py` | Main runner: reproduces findings F1–F4. |

## Methods implemented (subset of Scorio's 72)

| Family | Methods |
|--------|---------|
| Pointwise | `avg` (= Bayes_U@N, the gold standard), `bayes_uniform`, `bayes_greedy` (= Bayes_R0@N, greedy prior) |
| Pairwise voting | `borda`, `copeland` |
| Pairwise graph | `pagerank`, `rank_centrality` |
| Pairwise model | `bradley_terry_mle` (iterative scaling), `elo` (sequential) |

## Findings reproduced

**F1 (Table 1).** At N=80, all methods agree closely with the gold standard
(mean Kendall τ_b ≈ 0.93–0.96); several recover the exact ordering.

**F2 (Table 2).** At N=1, best methods reach τ_b ≈ 0.86 vs gold; the greedy
prior (`bayes_greedy`) helps on aligned benchmarks.

**F3 (Table 4).** The greedy prior always reduces variance (16–52%) but
biases the ranking when greedy-sampling alignment (τ_G-S) is low — Δτ turns
negative. Reproduced by varying `greedy_bias` in the data generator.

**F4 (Appendix C).** The minimal BT-vs-average counterexample at M_min=8:
marginal accuracies rank model 0 > 1 > 2, but the win-structure makes BT
rank 1 > 0 > 2. Exhaustive search confirms no disagreement exists for M ≤ 7.

## Known gaps / limitations

1. **Synthetic latents.** Real Scorio uses 20 reasoning LLMs on AIME/HMMT
   math benchmarks (7445 GPU-hours). We use a sigmoid skill-difficulty model
   so absolute τ_b values are indicative, not matched to the paper's tables.
2. **8 of 72 methods.** The 21-method N=1 tie (Table 18) is represented by
   the pointwise + graph/voting core that constitutes it; voting-rule tail
   variants (minimax, Nanson, Schulze) are omitted.
3. **Binary correctness only** — matches the paper's own scope (math
   reasoning). No partial credit / open-ended outputs.
4. **No vLLM serving** — R is synthesized, not generated by real LLMs.
