# iLLaDA — Improved Large Language Diffusion Models

A self-contained PyTorch implementation of the core ideas from **iLLaDA** (Nie et al., 2026), demonstrating masked diffusion language modeling with fully bidirectional attention.

## Paper

> *Improved Large Language Diffusion Models*
> Shen Nie, Qiyang Min, Shaoxuan Xu, Zihao Huang, Yuxuan Song, Yong Shan, Yankai Lin, Wayne Xin Zhao, Chongxuan Li, Ji-Rong Wen
> arXiv: 2606.25331, 2026

## Key concepts demonstrated

1. **Masked diffusion training**: Unlike BERT's fixed 15% masking, the masking ratio `t` is sampled uniformly from [0, 1] for each sequence. This continuous noise schedule makes it a diffusion process.

2. **Fully bidirectional attention**: No causal mask — the model attends to all positions simultaneously, enabling better reasoning on non-sequential tasks.

3. **Variable-length generation**: Text is generated by appending blocks of mask tokens and iteratively revealing them, enabling non-autoregressive generation that stops at EOS.

4. **Confidence-based MC scoring**: For multiple-choice questions, candidates are scored by greedily revealing answer tokens in order of highest model confidence and accumulating log-probabilities.

5. **Repeated data improvement** (key finding): The training script shows that loss keeps decreasing on repeated passes over the same tiny dataset — diffusion models are "super data learners" that don't overfit like autoregressive models.

## Architecture (toy model)

The implementation uses a small but architecturally faithful model:

| Component | Paper (8B) | This impl |
|-----------|-----------|-----------|
| Dim | 4,096 | 128 |
| Layers | 32 | 4 |
| Q heads | 32 | 4 |
| KV heads | 8 | 2 |
| FFN dim | 14,336 | 256 |
| Vocab | 155K | ~40 chars |
| Max seq | 8,192 | 64 |
